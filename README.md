# Требования к Payroll Manager

## Цель

Автоматизировать процесс выдачи заработной платы сотрудникам.

---

## Проблемы текущего процесса

- Зарплата поступает частями.
- Нужно самостоятельно выбирать, кому выдавать деньги.
- Возможны частичные выплаты сотрудникам.
- Можно забыть отметить факт выдачи.
- Нужно всегда знать остаток наличных.
- Руководству необходимо видеть процесс выдачи.

---

## Функциональные требования

### Получение наличных

Система должна позволять фиксировать поступление денежных средств.

Деньги могут поступать несколькими частями.

---

### Выдача зарплаты

Система должна:

- учитывать частичные выплаты;
- хранить историю всех выплат;
- автоматически рассчитывать остаток.

---

### Дополнительные расходы

Система должна учитывать незапланированные расходы.

Например:

- закупка материалов;
- аварийные расходы;
- прочие выплаты.

---

### Отчеты

Руководитель должен видеть:

- сколько денег получено;
- сколько уже выдано;
- сколько осталось;
- кому уже выдана зарплата;
- кому еще не выдана.
